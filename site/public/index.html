loopup v0.0.1

Runs your goal through five live tools

Type one goal. LoopUp runs it through five small tools that were each built and deployed separately. Each tool does its part, then loopup re-checks every step by asking each tool to confirm its own result. At the end you get one honest summary: what each tool did, whether it all checks out, and a brand-new reusable tool that was created from the whole run.
